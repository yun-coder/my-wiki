## 维护规则

1. **一页只回答一类问题。** 先写"这页解决什么问题"，再放内容；不写目录式空话。
2. **结论带条件和日期。** 模型、价格、产品状态会过期，写成「截至某日 / 在什么任务上」。
3. **链接只是证据，不是知识。** 一个工具最多一行加一句判断：什么时候选它、什么时候别选。
4. **事实、判断、猜测分开写。** 事实给来源；判断标明是判断；没有依据的不写。
5. **敏感信息不入库。** API Key、token、`.env`、日志、数据库文件一律不提交。
6. **不恢复自动化。** 本库回归"人读 + AI 读"的静态知识；需要采集时临时写脚本，不留常驻任务。
