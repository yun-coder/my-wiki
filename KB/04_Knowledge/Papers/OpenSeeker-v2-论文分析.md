# OpenSeeker-v2: 用高质量轨迹突破搜索 Agent 的极限

> **论文信息**
> - arXiv: [2605.04036](https://arxiv.org/abs/2605.04036)
> - 领域: 人工智能 (cs.AI)、计算与语言 (cs.CL)

> - 许可: arXiv 非独占分发
> - 背景: 纯学术团队开发，模型权重已开源

## 摘要
> 仅用 SFT（监督微调）+ 10.6k 高质量训练数据，30B 规模的 OpenSeeker-v2 在 4 个搜索 Agent 基准上全面超越通义 DeepResearch（CPT+SFT+RL 重磅管线），证明**数据质量远比训练管线复杂度重要**。

---

## 📖 一、问题背景

### 深度搜索 Agent 的工业垄断
深度搜索能力已成为前沿 LLM Agent 的核心竞争力，但其开发长期被工业巨头主导：

| 工业方案 | 典型管线 |
|----------|---------|
| 通义 DeepResearch | 预训练 → CPT → SFT → RL |
| OpenAI Deep Research | 大规模预训练 + RLHF |
| Perplexity Pro | 多阶段训练 + 在线搜索集成 |

**痛点**：整个管线资源密集，学术界几乎无法复现或参与竞争。

### 核心问题
> 能否用**更简单的训练方法**（仅 SFT）训练出**更强**的搜索 Agent？

---

## 🧠 二、核心方法

### 核心发现
**当数据足够"信息丰富"且"高难度"时，简单 SFT 出乎意料地强大。**

### 三大数据合成改进

| 改进 | 做法 | 目的 |
|------|------|------|
| **扩大知识图谱规模** | 增加知识图谱节点和边 | 更丰富的探索路径 |
| **扩展工具集规模** | 增加可用工具数量 | 更广泛的功能覆盖 |
| **严格的低步数过滤** | 只保留高效完成的轨迹 | 过滤掉冗余低效的探索 |

```
数据合成流程:
  问题 → Agent 探索(大知识图谱 + 多工具) → 收集轨迹
                                              ↓
                                    低步数过滤（只保留高效的）
                                              ↓
                                    10.6k 高质量训练数据
                                              ↓
                                      SFT 微调 → OpenSeeker-v2
```

### 关键数据
- **训练数据量**：仅 **10,600 条**轨迹
- **基座模型**：30B 参数规模
- **范式**：ReAct（推理 + 行动）
- **训练方法**：仅 SFT，无 CPT，无 RL

---

## 📊 三、实验结果

### 4 项基准全面 SOTA

| 基准测试 | OpenSeeker-v2 | 通义 DeepResearch (CPT+SFT+RL) | 提升 |
|----------|:---:|:---:|:---:|
| **BrowseComp** | **46.0%** | 43.4% | +2.6 |
| **BrowseComp-ZH** | **58.1%** | 46.7% | +11.4 |
| **Humanity's Last Exam** | **34.6%** | 32.9% | +1.7 |
| **xbench** | **78.0%** | 75.0% | +3.0 |

### 关键亮点
1. **BrowseComp-ZH 提升 +11.4%** — 中文搜索能力碾压级优势
2. **4/4 基准全部领先** — 无一落后
3. **纯学术团队 + 仅 SFT** — 历史首次在该规模和范式下达到 SOTA

---

## 💡 四、核心价值与意义

### 对学术界的意义
- **降低门槛**：不需要 CPT + RL 的重型管线，学术团队也能训练前沿搜索 Agent
- **数据优先**：证明了数据质量 > 训练管线复杂度
- **可复现**：开源模型权重 + 简单方法，社区容易复现和改进

### 方法论启示
```
工业界:  预训练 → CPT → SFT → RL  （昂贵、复杂、封闭）
OpenSeeker:  SFT only  （便宜、简单、开源）
                ↑
        高质量数据是关键
```

### 三个简单改进的普适性
1. **扩大知识图谱** → 可迁移到其他 Agent 领域
2. **扩展工具集** → 通用 Agent 训练思路
3. **低步数过滤** → 数据质量控制的简单有效手段

## 🔍 六、局限性与思考

### 当前局限
1. **30B 模型规模** — 相比工业级模型（如 72B+）仍有差距
2. **仅 ReAct 范式** — 未探索其他 Agent 架构（如 Plan-and-Solve）
3. **训练数据 10.6k** — 数据量小，泛化性需要更多验证
4. **7 页短报告** — 技术细节披露有限

### 延伸思考
- **数据 > 算法** 这个论点在越来越多场景被验证（ reminiscent of LLM scaling laws 中的 "data matters"）
- 低步数过滤本质上是**效率驱动的数据筛选**，这个思路可广泛应用于 Agent 训练
- 中文基准的大幅领先（+11.4%）暗示训练数据中中文高质量轨迹可能是关键差异
- 如果将此方法与 RL 结合，效果可能进一步提升
