## 二、核心项目详解

### 2.1 Agent 技能框架

#### agent-skills — 生产级 Agent 技能集
- **仓库**: [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)
- **说明**: 24 个结构化工作流，Markdown SKILL.md 格式
- **亮点**: 社区最火的 Agent 技能库（⭐ 74k+），涵盖开发/设计/研究等
- **核心模式**: `SKILL.md` 文件 + 斜杠命令系统，多 CLI 兼容（Claude/Gemini/OpenAI）
- **使用**: CodeCamp 已克隆，直接参考 `skills/` 目录下的 SKILL.md

#### chubbyskills — 信息采集与第二大脑
- **仓库**: [chubbyfish/chubbyskills](https://github.com/chubbyfish/chubbyskills)（Fork）
- **技术栈**: Python, SenseVoice, DeepSeek, Obsidian
- **核心技能**:
  - 多平台转录：抖音/B站/小红书/X/知乎/微博/YouTube/Podcast
  - 内容增强：content-enrich
  - 行业情报雷达：industry-intelligence-radar
  - 知识库管理：knowledge-base-management
  - 学习笔记自动化：learning-notes-automation
- **亮点**: 信息输入→加工→存储 全链路闭环

#### agency-agents — 232 个 AI 代理人格库
- **仓库**: [agency-agents/agency-agents](https://github.com/agency-agents/agency-agents)
- **说明**: 跨 16 个专业领域的 Agent 定义
- **领域**: 学术/设计/工程/金融/游戏/GIS/营销/产品/项目管理/销售/安全/空间计算/策略/支持/测试/付费媒体
- **格式**: Markdown Agent 定义，多 CLI 兼容

### 2.2 Agent 教程与基础

#### hello-agents — Datawhale 中文智能体教程
- **仓库**: [datawhalechina/hello-agents](https://github.com/datawhalechina/hello-agents)
- **目录结构**:
  - `code/` — 配套代码
  - `docs/` — 文档教程（多章节）
  - `Extra-Chapter/` — 扩展章节
  - `Co-creation-projects/` — 共创项目
- **覆盖主题**: LangGraph, AutoGen, MCP, A2A 协议
- **建议**: 系统学习 Agent 的首选教程

### 2.3 Agent 能力扩展

#### Agent-Reach — Agent 上网能力
- **仓库**: [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach)
- **技术栈**: Python, yt-dlp, MCP, 多平台 CLI
- **核心**: 赋予 AI Agent 访问互联网的能力（网页/视频/社交平台）
- **亮点**: 一键聚合互联网工具

#### intentos — 意图驱动 OS
- **仓库**: [intentos-ai/intentos](https://github.com/intentos-ai/intentos)
- **技术栈**: Python, Autogen, FastAPI, MiniMax-M3
- **核心**: AI 优先的连续画布设计，演示意图驱动操作系统概念

### 2.4 多 Agent 系统

#### council-of-high-intelligence — 18 历史人物 AI 角色审议系统
- **仓库**: [neobrutalist/council-of-high-intelligence](https://github.com/neobrutalist/council-of-high-intelligence)
- **亮点**: 多 LLM 路由，支持 Claude/OpenAI/Gemini 等供应商
- **配置**: 多供应商路由，可在 `configs/` 中调整
- **使用场景**: 多视角决策、辩论、创意启发

## 三、Agent 技术栈总结

| 层次 | 技术方案 |
|------|---------|
| **Agent 定义格式** | SKILL.md (Markdown) / YAML frontmatter |
| **Agent 框架** | LangGraph, AutoGen, Mastra AI, Claude Agent SDK |
| **通信协议** | MCP (Model Context Protocol), A2A (Agent-to-Agent) |
| **工具扩展** | MCP 服务器, CLI 工具, yt-dlp, Scrapling |
| **多 Agent 编排** | LangGraph (图状), AutoGen (会话式), council (审议式) |
| **记忆系统** | Mem0, 持久化记忆, 三层记忆架构 |

## 四、学习路径建议

1. **入门**: hello-agents 教程 → 理解 Agent 基础概念
2. **实践**: 参考 agent-skills 写自己的 SKILL.md
3. **深入**: 学习 MCP 协议 → 构建自定义 Agent 工具
4. **进阶**: 多 Agent 编排（council → intentos）
5. **生产**: chubbyskills 式的全链路信息处理
