## 五、OpenAI Prompt Engineering 指南

官方指南： [platform.openai.com/docs/guides/prompt-engineering](https://platform.openai.com/docs/guides/prompt-engineering)

核心原则：
1. **清晰具体** — 减少歧义，提供示例
2. **分步思考** — Chain-of-Thought 提升推理质量
3. **角色设定** — System Prompt 定义行为
4. **结构化输出** — JSON Schema / Markdown 格式
5. **Few-shot 示例** — 提供输入输出样例
