## 一、AI 视频生成全景

视频生成是当前最活跃的 AI 应用方向之一，从短视频、短剧到电影级制作工具齐全。

**两大主流路径：**
- **短剧/动漫/故事类** — 小说→剧本→分镜→画面→配音→合成 全流水线
- **短视频/营销类** — 脚本→配音→素材→字幕→合成 快速批量生产

## 二、核心项目详解

### 2.1 短剧/动漫/故事生成（重量级）

#### ArcReel — 小说转短视频全流程
- **仓库**: [ArcReel/ArcReel](https://github.com/ArcReel/ArcReel)
- **技术栈**: FastAPI, React, Claude Agent SDK, 多 AI 供应商
- **核心**: 多智能体编排，小说→分镜→画面→配音→合成完整流水线
- **状态**: CodeCamp 已克隆，本地可实验

#### OpenMontage — 开源 Agent 化视频制作
- **仓库**: [calesthio/OpenMontage](https://github.com/calesthio/OpenMontage)
- **技术栈**: Python, Remotion, 多视频/图像供应商
- **核心**: 12 条制作流水线，400+ Agent 技能
- **亮点**: 功能最全面的开源视频制作系统

#### Toonflow-app — AI 短剧工厂
- **仓库**: [HBAI-Ltd/Toonflow-app](https://github.com/HBAI-Ltd/Toonflow-app)
- **技术栈**: TypeScript, Express 5, Vercel AI SDK, ONNX
- **核心**: 三层 Agent 协作、章节事件图谱、持久化记忆
- **亮点**: 三层架构（Director/Artist/Memorial Agent），短剧创作最体系化

#### LumenX — 阿里巴巴 AI 漫剧平台
- **仓库**: [alibaba/lumenx](https://github.com/alibaba/lumenx)（内网）
- **技术栈**: Python, Next.js, FastAPI, DashScope
- **核心**: Studio + Playground 双模式创作
- **衍生**: yunspire（lumenx 衍生版，CodeCamp 已有本地定制）

#### ai_story — AI 故事视频自动化
- **仓库**: [xhongc/ai_story](https://github.com/xhongc/ai_story)
- **技术栈**: Python/Django, Celery, Vue
- **核心**: Pipeline 责任链模式，多 AI 服务编排

#### huobao-drama — AI 短剧生成平台
- **仓库**: 不明确（CodeCamp 本地项目）
- **技术栈**: TypeScript, Hono, Nuxt 3, Mastra AI
- **核心**: Mastra AI Agent 驱动的全自动化短剧生成

#### story-flicks — 故事短视频
- **仓库**: [alecm20/story-flicks](https://github.com/alecm20/story-flicks)

#### TypeTale — 字字动画 AIGC 视频
- **仓库**: [TypeTale/TypeTale](https://github.com/TypeTale/TypeTale)

### 2.2 短视频/营销视频生成

## 三、视频生成技术栈概览

| 技术组件 | 常见方案 |
|---------|---------|
| **前端框架** | React/Next.js, Vue/Nuxt 3 |
| **后端框架** | FastAPI, Django, Express 5 |
| **任务队列** | Celery, 内置 Pipeline |
| **AI 供应商** | DashScope(阿里), OpenAI, Claude, MiniMax, Kling, Vidu, Grok, FLUX |
| **视频渲染** | Remotion (React 组件渲染), FFmpeg |
| **字幕/配音** | TTS 引擎, SenseVoice, Whisper |
| **Agent 框架** | Claude Agent SDK, Mastra AI, LangGraph |

## 四、趋势判断

1. **短剧自动化是最大热点** — LumenX / Toonflow / ArcReel 三个项目都在做小说→短剧的全流水线
2. **Agent 化视频制作** — OpenMontage 400+ Agent 技能、Toonflow 三层 Agent 协作
3. **四模态融合** — Seedance 2.0 代表文本/图像/音频/视频一体化
4. **商业化接单** — 有戏AI、纳米大片等平台已打通变现
