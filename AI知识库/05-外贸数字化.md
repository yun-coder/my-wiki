## 一、外贸数字化全景

外贸 SaaS 工具收藏（29 个）是书签中数量最多的分类，覆盖了从获客到交付的完整链路。

```
获客 → 海关数据 → 客户管理(CRM) → 营销 → 单证 → 金融/风控 → 合规/翻译
```

## 四、个人关注重点

1. **AI 改造外贸全链路** — 从获取客户到单证处理到金融风控，AI 正在重塑每个环节
2. **数据驱动获客** — 海关数据（腾道/环球慧思） + AI 分析（Accio/TradingClaw）
3. **合规与翻译** — 外贸专业场景需要 DeepL + UNTERM 保证准确性
4. **营销模型** — Google Meridian 开源的 MMM 模型可用于外贸营销效果归因
