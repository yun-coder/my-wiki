# FFmpeg

## 是什么
FFmpeg 是一个开源的跨平台多媒体框架，用于处理音频、视频和其他流媒体数据。它提供了强大的命令行工具和库（libavcodec, libavformat, libavutil, libavfilter, libswscale, libswresample），支持广泛的编解码器和协议。

## 怎么用
1. **下载与安装**: 从 [ffmpeg.org/download.html](https://ffmpeg.org/download.html) 获取对应操作系统的预编译二进制文件或源码进行编译安装。
2. **基本转换**: 使用 `ffmpeg -i input.mp4 output.avi` 进行格式转换。
3. **提取音频**: 使用 `ffmpeg -i input.mp4 -vn audio.mp3` 提取音频轨道。
4. **视频裁剪**: 使用 `ffmpeg -ss 00:00:10 -t 00:00:05 -i input.mp4 -c copy output.mp4` 进行精确裁剪。
5. **添加水印**: 使用 `-filter_complex` 叠加图片或文字水印。

## 什么场景
- **视频预处理**: 在 AI 视频生成前，对素材进行格式统一、分辨率调整或片段裁剪。
- **批量处理**: 自动化脚本处理大量视频文件的转码、压缩或元数据修改。
- **流媒体处理**: 实时音视频流的录制、转发或格式转换。
- **故障排查**: 分析视频文件结构、编解码器信息以解决兼容性问题。

## 方法论: 如何更好生成视频
1. **标准化输入**: 确保所有源素材经过 FFmpeg 预处理，统一编码格式（如 H.264/H.265）、分辨率和帧率，以提高 AI 模型的处理效率和一致性。
2. **高效压缩**: 利用 FFmpeg 的 CRF（恒定质量因子）模式进行有损压缩，在保证视觉质量的前提下减小文件体积，便于传输和存储。
3. **自动化流水线**: 将 FFmpeg 命令集成到 CI/CD 或数据处理管道中，实现从原始素材到最终交付物的全自动视频生成流程。
4. **多语言字幕嵌入**: 在视频生成后，使用 FFmpeg 将生成的字幕文件（SRT/VTT）硬烧录或软封装到视频中，提升可访问性。
