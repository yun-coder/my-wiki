## 一、AI 网关与平台工具

### OmniRoute — 免费 AI 网关
- **仓库**: [OmniRoute/OmniRoute](https://github.com/OmniRoute/OmniRoute)（Fork）
- **技术栈**: TypeScript, Next.js 16, MCP/A2A, SQLite
- **核心**: 连接 237 家 AI 供应商（90+ 免费层）
- **亮点**: 支持 MCP + A2A 双协议，有 Electron 桌面版
- **状态**: CodeCamp 已克隆，可用作本地 AI API 聚合层

### local-deep-research — 本地化深度研究
- **仓库**: [local-deep-research](https://github.com/local-deep-research/local-deep-research)（Fork）
- **技术栈**: Python, Ollama, LangChain, SQLCipher
- **核心**: 多检索引擎 + 加密知识库，完全本地运行

### project-helper — GitHub 仓库学习助手
- **仓库**: 本写项目
- **技术栈**: Python, FastAPI, DeepSeek, Vue
- **核心**: 自动生成源码报告，分析 GitHub 仓库

### loop-engineering — Loop 工程自动化
- **仓库**: 源自 [alchaincyf/loop-engineering-orange-book](https://github.com/alchaincyf/loop-engineering-orange-book)
- **核心**: 自动从收件箱拾取任务，git worktree 隔离执行
- **关联**: my-wiki 项目中的 agentic-agent 就是基于 Loop Engineering 理念构建

### career-ops — AI 求职/Offer 管理
- **仓库**: 本写项目
- **技术栈**: Node.js, Playwright, Go
- **核心**: 职位评估、简历生成、Offer 管理

## 二、AI 语音工具

### Voicebox — 开源 AI 语音工作室
- **仓库**: [functime-ai/voicebox](https://github.com/functime-ai/voicebox)
- **技术栈**: Rust (Tauri), Python, React, MLX, MCP
- **核心功能**:
  - 7 种 TTS 引擎
  - 声音克隆
  - MCP 输出集成
- **亮点**: 桌面级（Tauri）语音工作室，MCP 协议集成

### JoyAI-Echo
- AI 语音交互实验项目，尚在早期
