## 一、技术栈总览

当前关注的前端技术栈以 **TypeScript 生态** 为核心，覆盖框架、UI 组件、可视化、图标、工程化等。

---

## 二、框架与核心库

| 技术 | 说明 | 链接 | 用途 |
|------|------|------|------|
| **NestJS** | Node.js 服务端框架 | [nestjs.com](https://nestjs.com/) | AI 项目后端首选（TypeScript/Decorator/模块化） |
| **Quasar Framework** | Vue 跨平台 UI 框架 | [quasar.dev](https://quasar.dev/) | 企业级桌面/移动端 |
| **Electron** | 桌面应用框架 | [electron.nodejs.cn](https://electron.nodejs.cn/) | AI 桌面工具（如 voicebox 使用 Tauri，类似理念） |
| **Zod** | TypeScript 数据验证库 | [zod.dev](https://zod.dev/api) | API Schema 验证，配合 AI Agent 输出校验 |
| **LeaferJS** | 2D 图形渲染引擎 | [leaferjs.com](https://www.leaferjs.com/ui/guide/) | 高性能 Canvas/WebGL 图形 |
| **glTF Viewer** | 3D 模型查看器 | [gltf-viewer.donmccurdy.com](https://gltf-viewer.donmccurdy.com/) | 3D 模型预览 |
