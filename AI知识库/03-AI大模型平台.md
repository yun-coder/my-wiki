## 五、成本策略

```
聚合平台（省钱）: SiliconFlow / OpenRouter → 多模型自由切换
直达平台（稳定）: 阿里百炼 / DeepSeek → 高并发场景
中转平台（方便）: CloseAI / AiHubMix → 国内直接访问
```

## 六、当前主力

- **推理/聊天**: DeepSeek / Claude
- **聚合兜底**: SiliconFlow / OpenRouter
- **视频生成依赖**: DashScope / MiniMax / Kling
- **个人开发**: Agnes（自定义 Agent 系统）
