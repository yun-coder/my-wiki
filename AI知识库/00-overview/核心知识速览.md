## 当前核心判断

- AI 的竞争重点从单模型能力转向 Agent、记忆、工具、治理和业务闭环。
- GitHub Star 只能代表关注度；采用项目要看许可证、更新、测试、部署和成本。
- 多 Agent 适合并行和角色分工，小任务优先使用单 Agent，避免协调成本。
- RAG 不等于记忆；长期记忆还要处理事实冲突、过期、删除和权限。
- 企业落地优先保证可观测、可审批、可回滚和可控成本，再追求更高自治度。
