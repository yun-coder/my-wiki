# AI 模型与工具评估

> 从旧全景总览拆分的评估框架｜更新：2026-07-27

旧全景文档包含一份按热度排列的模型与工具榜单。由于模型能力、价格和产品状态变化很快，本文件不延续固定名次，而把原有信息整理成可持续更新的评估维度。

## 一、评估维度

| 对象 | 核心维度 |
|---|---|
| 大语言模型 | 推理、代码、写作、长上下文、多模态、成本、延迟、可用性 |
| 图像生成 | 提示词遵循、文字渲染、风格一致性、编辑能力、可控性 |
| 视频生成 | 动作连贯、角色一致、镜头控制、音画能力、生成时长与成本 |
| Agent 框架 | 状态管理、工具调用、记忆、多 Agent、可观测性、部署复杂度 |
| RAG 工具 | 解析、召回、重排、引用准确性、评估体系、运维成本 |
| 开发工具 | 集成成本、自动化程度、可扩展性、隐私、安全与稳定性 |

## 二、候选模型与平台

| 类型 | 候选对象 | 主要观察点 |
|---|---|---|
| 通用模型 | Claude、GPT、Gemini、Qwen、DeepSeek、Kimi、GLM、MiniMax | 综合能力、价格、国内可用性 |
| 图像生成 | GPT Image、FLUX、Stable Diffusion/ComfyUI、Midjourney | 编辑、控制与工作流集成 |
| 视频生成 | Seedance、Kling、Vidu、Runway、CogVideo、Cosmos | 连贯性、可控性与生产流程 |
| Agent 框架 | LangGraph、AutoGen、Claude Agent SDK、Mastra、DeerFlow | 编排、记忆、工具和部署 |
| RAG | RAGFlow、LangChain、LlamaIndex | 数据接入、检索质量与评估 |

## 三、工具类别观察

| 类别 | 代表工具 |
|---|---|
| 视频生成 | Seedance、Kling、Vidu、Runway |
| 图像生成 | GPT Image、FLUX、ComfyUI |
| 语音 | ElevenLabs、Voicebox、ChatTTS |
| 网页抓取 | Crawl4AI、Firecrawl、Scrapling |
| 代码助手 | GitHub Copilot、Cursor、Codex、Claude Code |

## 四、更新规则

- 不使用永久固定排名；每次评估必须注明日期、任务和样本。
- 能力结论与价格、版本分开记录，避免模型升级后结论失真。
- GitHub Star 和社区热度只能表示关注度，不能替代质量评测。
- 每次实际试用结果写入 `10-资讯洞察库.md`，项目资料进入 `09-项目分类索引.md`。
