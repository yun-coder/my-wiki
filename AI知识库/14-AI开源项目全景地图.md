# AI 开源项目全景地图

> AI 开源生态的长期导航与选型参考。覆盖模型、推理、Agent、记忆、RAG、多模态、评测和行业应用。
>
> 更新：2026-09-28｜来源：GitHub 公开仓库、项目 README 与个人调研

## 一、先看结论

当前 AI 开源生态的主线，已经从“调用一个模型”转向完整系统：

```text
模型 → 推理部署 → Agent 编排 → 记忆/RAG → 工具与业务系统
     → 评测/观测/安全 → 可持续运行的数字员工
```

最值得持续关注的五个方向：

1. **Agent 团队化**：Paperclip、Orca、OpenRig、CrewAI、AutoGen。
2. **长期记忆化**：Hindsight、Mem0、Zep、GraphRAG。
3. **工具可调用化**：MCP、CLI-Anything、Univer、Computer Use。
4. **企业生产化**：Dify、RAGFlow、WeKnora、Langfuse、Open Code Review。
5. **本地化和开源化**：Ollama、llama.cpp、vLLM、ComfyUI、Whisper。

## 四、项目评估规则

GitHub Star 只表示关注度，不能直接代表质量。新增项目或决定采用前，至少检查：

- 最近提交、Issue 响应和版本发布频率
- 许可证是否允许个人或商业使用
- 是否支持本地部署、数据隔离和模型替换
- 是否有测试、文档、示例和可重复部署方式
- 模型成本、显存要求、延迟和并发能力
- Agent 是否具备权限边界、日志、审批和可回滚能力
- RAG 是否能提供引用、评测和错误记忆修正

## 五、当前判断

1. **Agent 编排会成为新的应用层基础设施**，但单 Agent、小任务不应过度引入多 Agent。
2. **记忆质量将比向量库品牌更重要**，需要处理事实冲突、过期和删除。
3. **企业采用的关键是治理，不是 Demo 效果**，审计、权限、成本和可恢复性必须前置。
4. **本地模型适合隐私和成本敏感场景**，云端模型仍适合复杂推理和高质量生成。
5. **多模态 Agent 会逐渐成为默认形态**，文档、浏览器、表格、语音和视频将被统一到工具链中。
