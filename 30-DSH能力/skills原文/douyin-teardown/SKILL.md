# 抖音爆款拉片

目标不是"描述视频内容"，而是回答三个问题：**它靠什么在 3 秒内留住人、靠什么让人看完、靠什么让人转发**，最后落成一份别人能照着复刻的方案。

## 一、抓素材

```bash
# 1) 链接 → video.mp4 + meta.json
node scripts/fetch.mjs "<抖音分享文案或链接>" "D:\智贸\08-拉片\<slug>"

# 2) 视频 → 切点/逐镜关键帧/联系表/音频
node scripts/frames.mjs "D:\智贸\08-拉片\<slug>\video.mp4" "D:\智贸\08-拉片\<slug>"
```

- 依赖 `yt-dlp`（`pip install yt-dlp`）与 ffmpeg。抓取失败时脚本会给出下一步：换电脑端完整链接、加 `--cookies-from-browser chrome`、或让用户手机保存 mp4 后直接跑第 2 步。
- `frames.mjs` 输出 `shots.json`（镜表 + 每镜中间帧）、`frames/shot-XX.jpg`、`contact-sheet.jpg`（12 格）、`audio.wav`。

### 台词转写（已装 faster-whisper）

```bash
python scripts/asr.py "<dir>\audio.wav" "<dir>\transcript.json" --model small   # 快；中文字错略多
python scripts/asr.py "<dir>\audio.wav" "<dir>\transcript.json" --model medium  # 准；CPU 约 1–2 倍时长
```

- CPU int8 实测：15 秒中文音频用 `small` 约 7 秒，`medium` 更准但慢 2–3 倍；60 秒以内用哪个都行。
- 输出带时间戳的分段（`segments[].start/end/text`），直接拿来做「逐句台词卡点」。
- 画面烧录字幕仍然要看：口播视频用 ASR，纯字幕视频用逐帧读字，两者互相校对。

## 二、看片（必须真的看图）

1. 先看 `contact-sheet.jpg` 建立整体印象；
2. 再按 `shots.json` 逐镜看 `frames/shot-XX.jpg`，**每镜记三件事**：画面主体与景别、屏幕上的文字/字幕（抖音多数视频把台词烧在画面上，逐镜读字就是免费的 ASR）、这一镜在叙事里干什么；
3. 跑 `asr.py` 拿带时间戳的台词（faster-whisper 已装在本机），再和画面字幕交叉核对；两边对不上时以画面字幕为准，并在报告里说明。

## 三、报告模板（写进 `<slug>\report.md`）

```markdown
# <标题> 拉片报告

## 0. 基本信息
账号 / 时长 / 点赞·评论·转发 / 发布时间 / BGM（meta.json 取）

## 1. 3 秒钩子（决定 70% 完播）
- 第一帧是什么（画面 + 字幕 + 音效）
- 它在制造什么：悬念 / 冲突 / 反常 / 强利益 / 视觉冲击
- 为什么划不走（一句话结论）

## 2. 镜头表（按 shots.json）
| # | 时间 | 时长 | 景别/运镜 | 画面 | 字幕/台词 | 作用 |
（作用只能填：钩子 / 铺垫 / 冲突 / 转折 / 证据 / 爽点 / 收尾 / 引导）

## 3. 节奏曲线
- 平均镜长、最短镜长、切镜密度随时间的变化
- 信息点间隔（每几秒给一个新信息）
- 哪里是"防划走"的补丁（换景、变速、加字幕、加音效）

## 4. 情绪弧
起点情绪 → 中段加压 → 释放点 → 结尾动作引导（关注/评论/转发/购买）
用一句话写出它的"预期违背"在哪。

## 5. 爆款因子归因
| 因子 | 证据（哪一镜/哪句） | 强度 1-5 | 可否复刻 |
内容因子：选题 / 反差 / 干货密度 / 情绪价值
形式因子：钩子设计 / 节奏 / 字幕排版 / 声音
算法因子：完播设计 / 互动引导 / 标签与发布时间

## 6. 一句话结论
"它火是因为 ___，最容易被忽略的是 ___，最难复刻的是 ___。"

## 7. 复刻方案
- 可直接复用的结构（几段式，每段几秒）
- 需要替换的变量（人物/场景/产品/台词）
- 风险点（同质化、审核、版权 BGM）
- 开拍清单：道具、机位、字幕样式、BGM 类型
```

## 四、产出复刻分镜

在 `<slug>\replicate.json` 写一份可执行分镜，字段与 `shot-contract` 对齐（`scenes[].beats[].shots[]`，每镜含 `prompt`、`duration`、`light`、`shot_size` 等）。**要真正送「分镜出片」或 `h3_generate_video` 之前，先加载 `shot-contract` 技能**，用它把复刻分镜过一遍 13 道质量门，别绕过门禁直接生成。

## 五、硬约束

- **不要凭标题编内容**：所有结论要有镜号或字幕原文作为证据，写不出证据的就标"推测"。
- **不要把"点赞高"当分析**：点赞数是结果，报告要解释过程。
- 抓不到视频就停下来说明卡在哪一步，不要用搜索到的二手描述冒充拉片。
- 台词版权与 BGM 版权在复刻方案里要单独提示。
