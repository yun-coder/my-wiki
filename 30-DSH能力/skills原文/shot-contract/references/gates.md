# 13 道门

全部门都是**存在性检查**，不是品味判断：通过不代表好看，只代表结构没塌。品味那部分仍然要人看。

| 门 | 查什么 | 失败时怎么修 |
|---|---|---|
| G01 结构完整 | 三个数组、id 唯一、节拍字段齐全、有 `targetSeconds` | 补齐字段；缺目标时长就没法验收 |
| G02 节拍认领覆盖 | 每拍恰好一次、连续、顺序不回退、每镜至少一个动作拍 | 补认领 / 合并重复 / 把跳拍补成连续段 |
| G03 认领不跨场 | 一镜的节拍同属一场，且与镜头 `scene` 一致 | 换景处断开成两镜 |
| G04 时长预算 | 单镜区间、单段上限、总时长容差、节拍合计对账 | 先砍动作拍，再压台词；超段就拆段 |
| G05 台词装得下 | 按语速折算的台词时长 ≤ 镜头时长 | 拆镜、删词、或加时长（在单镜上限内） |
| G06 同框人数 | `inFrame` 人数 ≤ 上限，且不能为空 | 拆镜，或让人物退出画面 |
| G07 现场表完整 | 七列 + 每个人的 who/pos/facing 非空、非占位词 | 把"同上"改成实际内容 |
| G08 反应镜反打 | `kind: reaction` 的机位侧不能与上一镜相同 | 换到被反应对象那一侧 |
| G09 锁行逐字 | prompt 包含脚本生成的锁行原文 | 用 `locks` 重新生成并替换 |
| G10 台词逐字 | prompt 含每一条认领台词的原文 | 改 JSON 或改 prompt，让两边一致 |
| G11 禁用词 | 空话形容词、成语、肌肉清单 | 换成情绪词 + 身体锚点 |
| G12 终点在画面内 | `lastFrame` 不含"走出画面"类结果 | 改动作，或把结局交给下一镜 |
| G13 单一动作 | `action` 不含"然后/接着/随后"、不含"一边…一边" | 拆镜 |

## 常见组合，先看这里

- **G02 + G04 一起响**：镜头认领的节拍和时长对不上，通常是改剧本后只改了一边。先定节拍，再定时长。
- **G09 反复响**：你在手写锁行。用 `locks` 输出粘贴，别自己敲。
- **G10 反复响**：台词在 JSON 和 prompt 里各改了一版。以 JSON 为准。
- **G08 和 G12 一起响**：反打方向错了，导致"最后一帧"落在镜头背后。先修机位，再修终点。

## 加固

- 想加自己的禁用词：`params.traps` 追加，不要改脚本。
- 换模型：只改 `params` 的时长与人数上限，不要放宽门。
- 每次失败都记一条：这道门为什么响。反复响的门，说明提示词写法有问题，改写法比改门划算。
