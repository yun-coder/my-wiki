# 现场表

## 先有平面图

表之前先写三到四句**别人能照着画出来**的平面图：地标（门、桌、柜台、窗、擂台）、开场谁在哪、朝向什么、光源在哪、什么颜色。写明轴："主位正对大门""柜台在门的右手边"。画不出来的平面图，填不出表。

## 七列的含义，和空着时模型的默认值

| 列 | 写什么 | 空着时模型会用什么 |
|---|---|---|
| 机位侧 | 相对某个**地标**的哪一侧，加景别（全景/中景/近景/特写/插入） | 这个场景最常见的构图；主位正对镜头 |
| 画面内 | 每个主要人物在哪、朝向谁；群演只写一次 | 人物停在上一个镜头的位置 |
| 视线 | 谁看什么；反应镜的机位要站在"被反应的东西"那一侧 | 眼睛看镜头，看空气 |
| 动作 | 这一镜唯一的一件事；反应写成"情绪词 + 一个身体锚点"；道具写成一只手加一个倾斜；台词写成词 + 声音 + 眼睛 | 只活下来第一个动词，其余丢弃 |
| 其他人 | 画面里其他人手头的一句闲事 | 全体冻结，或者自作主张 |
| 光 | 光源和颜色，用与第一行相同的措辞 | 漂移，暖变冷 |
| 最后一帧 | 这镜结束时画面里留着什么，必须从"机位侧"看得见 | 一个这个机位看不到的结局 |

## 填表的硬规矩

- 空格、"默认""随意""同上"都算没填。必须把词重复写出来，不能写"同前"。
- 人物在两地之间移动，就给它一行，机位放在它经过或朝向的位置。从门口直接切到桌边的手，就是瞬移。
- 反应镜的机位在被反应对象那一侧。主机位是越过他肩膀朝门，反打就从门那边拍他。
- "最后一帧"要跟"机位侧"对得上：特写不能结束在门口的水洼上；想看水洼，给它一个插入镜。
- 位置一律相对地标写，不相对上一个镜头写。

## 纸面预演（免费，先做这个）

把填好的表当成一个**从没和你见过面的剧组**，一行一行念，并回答：

- 机位在哪？
- 每个人朝哪？
- 要反应的那个人，真的看得见被反应的东西吗？
- 上一个人在上一行哪里？如果换了地方，哪一行把他走过去的？
- 其他人此刻在干什么？
- 写了什么情绪，身体做了什么？
- 最后一帧画面里留着什么？

任何一处答"没写""应该吧"，都是一个在纸上就能抓到的错。纸面预演不要钱，一次生成要钱，重生成还要一次。

## 输出

```bash
node scripts/check.mjs table <file.json>
```

打印出 Markdown 现场表，跟提示词一起交付——让付钱的人在生成之前先能核对几何。
