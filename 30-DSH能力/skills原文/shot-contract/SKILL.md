# shot-contract

一句话：**模型会把空格填成默认值，而默认值永远不戏剧。** 所以表先于散文，节拍先于镜头。

这个 skill 只做两件事，两件事都必须过脚本：

1. **节拍认领**：戏被拆成编号节拍，每个镜头认领**连续**的几个节拍。谁的戏谁认领，漏了、重了、顺序乱了、跨场了，脚本当场点名。
2. **现场表 + 锁行**：每个镜头先有一行七格的表（机位在哪一侧、画面里有谁、视线落点、唯一动作、别人在干什么、光、最后一帧），散文由表生成，每镜结尾逐字复述锁行（光 / 身份 / 位置 / 朝向 / 机位侧）。

模型无关：这里没有参考图标记、没有秒数语法、没有厂商标记。要套某家模型的语法，放在最后一层，且**不许改动表与锁行**。

## 什么时候用

- 要出分镜、镜头表、切镜、首尾帧，或给一段戏写提示词。
- 已经有一条生成结果不对：人物瞬移、切镜后光变了、同一个动作糊成一团、台词对不上、情绪读不出来。
- 要做多镜连续（同一场戏拆成几段生成），需要每段的落点和入口对得上。
- 只在写文案、选音乐、做后期剪辑时：不需要本 skill。

## 工作流

**Step 0 定参数与画幅。** 读 `params`：单段生成上限、单镜时长区间、语速（字/秒）、容差、同框人数上限。这些是**默认值不是定律**，换模型就改这里，不要改规则本身。目标总时长写进 `targetSeconds`。

**Step 1 拆节拍。** 把戏拆成 `beats`：每拍只做一件事，`kind` 是 `action` 或 `line`；台词拍必须有 `speaker`，文本逐字保留；每拍给 `durationSec`（台词按字/秒折算，动作按拍估），并标 `scene`。

**Step 2 认领。** 每个镜头 `claims` 一段**连续**节拍，写 `scene`、`segment`（一次生成的批次）和 `durationSec`。规则：
- 一个节拍恰好被一个镜头认领，顺序不回退；
- 一镜不跨场；换景必换镜；
- 一镜至少一个动作拍（纯对白镜头没有画面可拍）；
- 认领节拍合计 ≈ 镜头时长；一段合计 ≤ 单段上限。

**Step 3 填现场表。** 每镜填七格（机位侧含景别）：`camera.side`、`camera.size`、`inFrame[]`（who/pos/facing）、`eyeline`、`action`、`others`、`light`、`lastFrame`。任何一格写"默认 / 随意 / 同上 / ——"都等于没写，门会拦。反应镜要反打：机位换到被反应对象那一侧。

**Step 4 由表成文。** 散文只写表里有的东西，顺序是：切/机位 → 动作与表情 → 位置变化 → 这一镜的声音 → 台词 → 锁行。锁行**不要手写**，用脚本生成后逐字贴进去：

```bash
node scripts/check.mjs locks <storyboard.json>
```

**Step 5 过门。** 不能跳：

```bash
node scripts/check.mjs check <storyboard.json>
```

13 道门全绿才交付。交付物三件一起给：分镜 JSON、现场表（`check.mjs table`）、每镜提示词。

## 命令

```bash
node scripts/check.mjs check  <file.json>   # 13 道门，失败退出码 1
node scripts/check.mjs table  <file.json>   # 打印 Markdown 现场表
node scripts/check.mjs locks  <file.json>   # 打印每镜锁行
node scripts/selftest.mjs                   # 自测，不调模型不花额度
```

脚本零依赖、只读 JSON、不联网、不用随机数和时钟，同一份输入永远同一份输出。

## 参数（默认值，按模型改）

| 字段 | 默认 | 含义 |
|---|---|---|
| `maxSegmentSeconds` | 15 | 一次生成能扛住的最长时长；超了就拆段 |
| `minCutSeconds` / `maxCutSeconds` | 2 / 5 | 单镜时长区间 |
| `charsPerSecond` | 4.5 | 台词折算语速 |
| `tolerance` | 0.15 | 总时长相对目标的容差 |
| `maxPeoplePerFrame` | 3 | 同框人数上限，超了拆镜 |
| `beatBudgetEpsilon` | 0.5 | 节拍合计与镜头时长的允许误差（秒） |
| `traps` | 内置词表 | 额外禁用词，追加到默认表后 |

## 反例墙（每条都来自一次真实的失败）

| 写错的 | 模型会给你 | 改法 |
|---|---|---|
| 情绪用成语："脸沉下来" | 一张发灰的脸 | 一个情绪词 + 一个身体锚点："压着火，指尖在桌沿收紧" |
| 群演写"众人不动" | 一屋子人偶 | 每人一句手头的闲事，且持续到镜尾 |
| 一镜堆四个动作 | 只活下来第一个 | 一镜一件事，走位单独成镜 |
| 门到桌之间不写走位 | 人物瞬移 | 每次横穿房间都给它一个镜头 |
| 只写身份不写位置 | 她站在上一个镜头的门口说台词 | 锁行每镜重述位置、朝向、机位侧 |
| 表情只写"平静" | 死脸 | 声音、眼睛、说完最后一个字之后的脸 |
| 让最后一帧落在门外 | 镜头容纳不了的结局 | 改动作，或把结局交给下一个镜头 |

## 不做什么

- 不写任何模型专有语法（参考图标记、时间戳、参数键）；需要时由调用方最后套壳。
- 不生成图片或视频，也不评判画质；它保证的是**结构成立**，不是好看。
- 不替代剧本：戏还是人写的，它只保证戏被完整地认领、并且拍得出来。
