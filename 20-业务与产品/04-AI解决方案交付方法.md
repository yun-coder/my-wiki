# AI 解决方案交付方法

> 这页解决一个问题：**作为 FDE，接到一个客户需求后，从诊断到验收按什么动作走，哪些话不能说。**

## 一、角色定位

FDE（Forward Deployed Engineer）不是售前，也不是外包实施：

- 对**业务结果**负责，不对"模型效果"负责。
- 能直接改代码、改流程、改数据，不停留在出方案。
- 是客户业务与技术之间的翻译器：把"我想要 AI"翻译成"哪个环节、什么指标、谁来验收"。
- 交付的终点不是上线，是**客户能自己跑下去**。

## 二、诊断：五个必问

1. **现在这个环节谁在做、一天做多少、花多久？** 没有基线就没有 ROI。
2. **做错的代价是什么？** 决定要不要保留人工确认。
3. **数据在哪、什么格式、谁有权限？** 决定可行性与部署形态。
4. **系统边界在哪？** 要接 CRM / ERP / 邮件 / 网站，接口开放程度决定工期。
5. **谁签字验收、看哪个指标？** 立项前就要有人名和指标，否则永远验收不了。

诊断产出：一张现状流程图（标注人工节点与耗时）+ 一份数据可得性清单 + 一个可量化的目标。

## 三、方案设计

方案 = **能力底座 + 垂直方案 + 交付形态**。

| 层 | 内容 | 复用性 |
|---|---|---|
| 能力底座 | 模型接入、Agent 编排、知识库、工作流、评测 | 高，跨客户复用 |
| 垂直方案 | 外贸获客、单证审核、内容生产、客户跟进 | 中，按行业沉淀 |
| 交付形态 | SaaS / 私有化 / 项目制 | 低，按客户定 |

设计时守三条：

- **先窄后宽**：一个环节做到可验收，再扩第二个，不要一次做全链路。
- **先增强后替换**：在客户现有系统上增强，替换类项目风险最高。
- **先规则后模型**：能用规则判定的（格式、必填、金额一致性）不要交给模型。

## 四、交付节奏

| 阶段 | 周期 | 产出 | 验收 |
|---|---|---|---|
| POC | 1–2 周 | 单点能力在真实样本上的效果 | 20–50 条样本通过率 |
| 试点 | 3–6 周 | 接入真实系统，小范围使用 | 节省工时 / 错误率下降 |
| 推广 | 1–3 月 | 全量上线 + 培训 + 运维手册 | 业务指标稳定达标 |
| 运营 | 持续 | 监控、迭代、成本优化 | 月度复盘 |

每个阶段都要有"退出条件"：不达标就停，不追加投入。这是保护双方的动作。

## 五、验收：业务指标优先

| 类型 | 例子 | 说明 |
|---|---|---|
| 业务指标 | 单证差错率、人均处理量、回复率、页面收录数 | 客户真正关心的 |
| 过程指标 | 人工修改率、平均处理时长、拒答率 | 用来诊断，不用来验收 |
| 技术指标 | 准确率、延迟、成本 | 内部看板 |

**判断**：只报技术指标的交付，三个月后会被问"所以省了多少钱"。

## 六、报价与商务

三种模式，按客户成熟度选：

- **诊断/咨询**：按人天或固定价，产出诊断报告与方案。适合还没想清楚的客户。
- **项目制**：按范围报价，分期付款（启动 / 试点验收 / 上线）。范围写清"不包含什么"。
- **订阅/SaaS**：按账号或用量。适合标准化程度高的环节。

定价原则：**按客户获得的价值定价，不按 token 成本加价**。报价单上写清：交付物、验收标准、变更流程、数据责任、退出条款。

## 七、风险与话术边界

| 不能说 | 应该说 |
|---|---|
| "准确率 99%" | "在你们这 50 条样本上通过 X 条，错误集中在 Y" |
| "能完全替代人工" | "AI 起草、人确认，预计减少 Z% 工时" |
| "什么都能做" | "这个环节能做，那个环节建议先上规则" |
| "模型会自动学习" | "需要我们定期用新样本调优" |
| "数据绝对安全" | "数据走私有化部署 / 脱敏后调用，权限这样控制" |

合同层面必须写清：AI 输出由谁审核、错误责任怎么分、数据归属与删除、模型供应商变更如何处理。

## 八、复盘与沉淀

每个项目结束做三件事：

1. **失败模式入库**：这次哪里翻车（数据、集成、期望、验收），写进知识库。
2. **可复用件抽出**：提示词、工具、评测集、部署脚本沉淀到底座。
3. **客户侧能力移交**：运维手册 + 培训 + 一个能自己改的配置入口。

## 九、交付前检查清单

- [ ] 有基线数据（现在多慢、多贵、多容易错）
- [ ] 有明确的验收人与指标
- [ ] 数据权限与脱敏方案确认
- [ ] 系统集成点与接口文档拿到
- [ ] POC 样本是真实业务数据
- [ ] 有回滚方案与人工接管入口
- [ ] 报价范围写清"不包含什么"
- [ ] 合同写了 AI 错误责任与数据归属
